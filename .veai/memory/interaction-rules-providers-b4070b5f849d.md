## Правила взаимодействия с провайдерами

1. **Авторизация** — если провайдер требует авторизацию (редирект на логин, blocked state и т.д.), агент НЕ пытается обойти это, а сразу просит пользователя авторизоваться вручную. Сообщение: "Провайдер X требует авторизацию. Пожалуйста, войдите в аккаунт в браузере."

2. **GLM версия** — основная версия GLM: **glm-5.2**, не glm-4-plus или другая. При выборе модели в запросах к GLM использовать glm-5.2.

3. **Разные вкладки** — каждый провайдер (GLM, Qwen, DeepSeek, Kimi) открывается в отдельной вкладке браузера. НЕ переиспользовать одну вкладку для нескольких провайдеров. Использовать `browser_navigate` для создания/переключения между вкладками.
