# Kimi: Полный обзор бесплатных функций

*Источник: Чат с Kimi AI (K2.6), 2025-07-15*

## ⚠️ Важно: Нет публичного API
Kimi **не предоставляет публичного API** для интеграции. Все функции доступны только через веб-интерфейс (kimi.com). Browser automation через Playwright — единственный способ интеграции.

---

## 1. Kimi Code (Код)
**Что делает:** Помощник для написания, отладки и рефакторинга кода. Поддерживает множество языков.
**Доступ:** Встроен в основной чат. Есть специальный режим "Kimi Code" (иконка `</>` в интерфейсе).
**Особенности:**
- Поддержка длинного контекста (до 2 млн токенов)
- Может анализировать целые репозитории (загрузка ZIP-архива)
- Генерация unit-тестов
- Объяснение ошибок компиляции/выполнения

## 2. Kimi Claw (Поиск в реальном времени)
**Что делает:** Агентный поисковик, который самостоятельно ищет информацию в интернете, анализирует найденное и выдаёт структурированный ответ с источниками. Работает как "глубокий поиск" — может делать несколько итераций поиска, уточняя запросы.
**Доступ:** Включается через переключатель "Поиск" (🔍) в чате или автоматически при запросах, требующих актуальных данных.
**Особенности:**
- Показывает ход рассуждения (chain of thought)
- Приводит ссылки на источники
- Может искать на китайском и английском языках
- Работает с актуальными новостями и событиями

## 3. Deep Research (Глубокое исследование)
**Что делает:** Расширенный режим исследования, который проводит многошаговый анализ темы: формирует план исследования, собирает информацию из множества источников, синтезирует отчёт.
**Доступ:** Отдельная кнопка/режим в интерфейсе.
**Особенности:**
- Генерация подробных отчётов с разделами
- Многоступенчатый анализ
- Автоматическое цитирование источников

## 4. Agent Swarm (Рой агентов / Мульти-агент)
**Что делает:** Система, где несколько специализированных AI-агентов работают параллельно над сложной задачей. Например, один агент ищет информацию, другой пишет код, третий проверяет факты.
**Доступ:** Более продвинутая функция, доступна через sidebar.

## 5. Kimi WebBridge (Веб-мост)
**Что делает:** Позволяет Kimi взаимодействовать с внешними веб-сервисами и API. Технически это система плагинов/инструментов, которая расширяет возможности модели за счёт интеграции с внешними данными и сервисами.
**Доступ:** Через специальные интеграции в интерфейсе. Устанавливается как browser extension: "One-click Install Kimi WebBridge — Let AI use the browser like a human"

## 6. Slides (Презентации)
**Что делает:** Генерация слайд-презентаций (PPT) по текстовому описанию. Создаёт структуру, подбирает дизайн, генерирует содержимое слайдов.
**Доступ:** Команда в интерфейсе или запрос типа "Создай презентацию о..."
**Ограничения:** Формат и стили ограничены встроенными шаблонами.

## 7. Websites (Генерация сайтов)
**Что делает:** Создание простых веб-страниц/сайтов по описанию. Генерирует HTML/CSS/JS код, который можно сразу просмотреть или скачать.
**Доступ:** Через запросы на генерацию веб-страниц.

## 8. Docs (Документы)
**Что делает:** Работа с текстовыми документами — создание, редактирование, форматирование. Можно загружать документы для анализа (PDF, Word, TXT и др.) и просить их переписать, суммаризировать или дополнить.
**Доступ:** Загрузка файлов через интерфейс чата. Поддерживаются файлы до сотен мегабайт благодаря длинному контексту.

## 9. Sheets (Таблицы)
**Что делает:** Генерация и работа с табличными данными (похоже на Excel/Google Sheets). Создание таблиц по описанию, анализ данных, формулы.
**Доступ:** Через запросы на создание таблиц или анализ загруженных CSV/Excel файлов.

---

## Slash-команды
Kimi **не использует классические slash-команды** (типа `/code`, `/search`). Вместо этого:
- Функции активируются через кнопки в интерфейсе (Поиск, Код, Презентации и т.д.)
- Или через естественно-языковые запросы ("найди в интернете...", "создай презентацию...", "напиши код для...")
- `Type "/" to quickly access skills` — это меню быстрого доступа к режимам sidebar

## API для разработчиков
Официального публичного API **нет**. Moonshot AI предоставляет API только для корпоративных клиентов.

## Документация
Публичной документации API не существует. Есть:
- Help Center / Справочный центр в самом интерфейсе Kimi
- Официальный сайт: kimi.moonshot.cn (китайский) или kimi.com (международный)
- Обновления функций публикуются в официальных каналах компании

## Рекомендации Kimi по интеграции через Playwright
1. **Авторизация:** Потребуется обходить систему логина (телефон или email + код)
2. **Селекторы:** Интерфейс динамический, селекторы могут меняться
3. **Rate limiting:** Будьте осторожны с частотой запросов, чтобы не получить бан
4. **Контекст:** Kimi отлично работает с длинным контекстом — используйте это для загрузки больших файлов
5. **ToS:** Термины использования могут запрещать автоматизацию — изучите
