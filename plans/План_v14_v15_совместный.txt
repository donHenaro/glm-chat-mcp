| playwright-extra | ✅ npm v4.3.6, 735K/week | JS stealth | P1 — документация как fallback |

### Что НЕ сработает через MCP Playwright (ограничение архитектуры):
| Фича | Почему недоступна | Альтернатива |
|-------|-------------------|-------------|
| page.route() | Нет в MCP API | ✅ JS injection (network-hooks.js) |
| exposeFunction() | Нет в MCP API | ✅ Poll через browser_evaluate |
| storageState() | Нет в MCP API | ✅ JS-level cookies/localStorage |
| CloakBrowser launch | MCP сервер управляет браузером | ✅ Документация для пользователя |
| CDPSession | Нет в MCP API | ⚠️ browser_network_requests |

### Собственное дополнение к GLM-плану:
1. **provider-adapter.js** — GLM не предусмотрел унифицированный адаптер как отдельный модуль
2. **Идемпотентность всех скриптов** — безопасно вызывать многократно (GLM не упомянул)
3. **Memory limits в netBuffer** — 50 записей max (GLM не учёл утечки памяти)
4. **Session validation** — проверка возраста < 7 дней (GLM не учёл устаревание)

## 4. План доработок (v14.0 → v15.0)

### P1 — Следующий приоритет (4 дня)

#### 4.1 AI-powered extract fallback (1 день)
- Если network buffer пуст И DOM-селекторы не нашли ответ
- Использовать browser_snapshot для анализа accessibility tree
- Парсить текст ответа из snapshot
- Файл: `scripts/ai-extract.js`

#### 4.2 Улучшение progress-monitor.js (0.5 дня)
- Интеграция с network-hooks.js для real-time SSE-мониторинга
- `window.__netBuffer.getLatestTokens()` для progressive reading
- Показ хода стриминга (кол-во токенов, ETA)

#### 4.3 Debug tracing (0.5 дня)
- `scripts/debug-trace.js` — логирование всех действий
- Сохранение трейса в `log/YYYY-MM-DD/trace-*.json`
- Формат: [{timestamp, action, result, duration}]

#### 4.4 Auto-init при первом обращении (1 день)
- SKILL.md: обновить workflow — шаг 3.5 "Установить network hooks"
- Агент автоматически инъецирует network-hooks.js при переходе на вкладку
- Проверка `window.__netHooksInstalled` — если false, установить

#### 4.5 Multi-provider интеграция с adapter (1 день)
- Обновить multi-provider.js для работы с provider-adapter
- Использовать `window.__adapter.send()` вместо прямых DOM-операций
- Сбор ответов через `window.__adapter.read()` с source индикацией

### P2 — Перспективные (7 дней)

#### 4.6 OpenAI-совместимый API слой (3 дня)
- HTTP-сервер с /v1/chat/completions
- Работает через наш MCP Playwright → браузер → провайдер
- SSE-streaming в OpenAI-формате
- Интеграция с Cline, Roo-Code, openclaw

#### 4.7 CloakBrowser MCP сервер (2 дня)
- Кастомный MCP Playwright сервер с CloakBrowser вместо Playwright
- `npm install cloakbrowser` → автозамена
- Конфигурация: humanize, proxy, geoip

#### 4.8 CDP interception (1 день)
- Для провайдеров с WebSocket-ответами
- Через browser_network_requests MCP инструмент

#### 4.9 HTTP bridge standalone (1 день)
- Express-сервер как альтернатива MCP
- Для использования не из IDE
